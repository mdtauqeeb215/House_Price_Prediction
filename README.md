# 🏡 House Price Prediction

A Machine Learning web application that predicts house prices based on property features such as area, number of bedrooms, bathrooms, and location.

🚀 **Live Demo:** [Try the House Price Prediction App](https://housepriceprediction-pv4jfxswwefdgsse9yycr5.streamlit.app/)

## 📌 Project Overview

The House Price Prediction project uses machine learning to estimate property prices from user-provided inputs. It includes an interactive web interface built with Streamlit, allowing users to explore the dataset and generate house price predictions.

## ✨ Features

- 🏠 Predict house prices using property details
- 📐 Input property area, bedrooms, and bathrooms
- 📍 Select a property location
- 📊 Explore dataset information and visualizations
- 🖥️ Interactive dashboard built with Streamlit
- 🌐 Deployed as a live web application

## 🛠️ Technologies Used

- **Python** — Programming language
- **Pandas** — Data manipulation and analysis
- **Scikit-learn** — Machine learning model and preprocessing
- **Matplotlib** — Data visualization
- **Streamlit** — Interactive web application
- **Git & GitHub** — Version control and project hosting

## 🤖 Machine Learning Workflow

1. Load and explore the house price dataset.
2. Prepare property features for model training.
3. Preprocess numerical and categorical data.
4. Train a Linear Regression model.
5. Use the trained model to predict house prices.
6. Display predictions through the Streamlit interface.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/mdtauqeeb215/House_Price_Prediction.git
cd House_Price_Prediction
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
